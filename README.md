# Lanka ki Chhatein

A 3D browser game set in Lanka at night, built with three.js.

## Run the prototype

```bash
python3 -m http.server 8765 --directory prototype
```

Then open http://localhost:8765/lanka-ki-chhatein.html (internet needed for the three.js CDN).

## Folders

- `prototype/` – the playable game (HTML + JS, models, textures, audio)
- `design/` – game design doc and reference images
- `research/` – technical breakdown of a reference web game
